# Complex CSH Tracker
 1. **Why did I create this?**
 My school runs on a very old tracking system for CSH (Community Service Hours) meaning it was hard for us students to see how much we have as well as see what happens to our CSH requests. I made this to solve this problem and decided to join stardance for the fun of it  :O
2. **What's so cool about it?**
Some features of this is the ability to log in to your account and request as well as see your history all in one website. Teachers also have it easy with a quick and simple UI for approving and denying request as well as adding notes for students to review and improve their future request. Additonally, bulit in Google-OAuth and Drive/Picker allows for student to quickly add vouch files to prove their request. 

TLDR: A Tracker that has
- Login/Signup
- Oauth (NOT A VERIFED APP YET SO UNFORTUNELY CANT USE DRIVE/PICKER)
- Drive/Picker
- Approval
- Hour goals
- Onboarding (somewhat)
